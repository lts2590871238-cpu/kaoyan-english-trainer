# 轩轩冲刺50分大作战！ V6

这是 2020—2026 考研英语一真题训练网站的重构版本。

## 目标

- 100 天，每天约 20–30 分钟。
- 每天 30 个词汇项目；基础计划按高频:中频:低频 = 5:3:2。
- 每天英译汉 2 句、汉译英 2 句。
- 单数学习日做自由翻译 2 句；双数学习日做成分分析 2 句。
- 成分分析共 100 句：精确拆分 30、粗略拆分 30、抓主干 40。
- 四个句池严格互斥：英译汉 200 + 汉译英 200 + 自由翻译 100 + 成分分析 100 = 600 句。
- 复习采用本地间隔记忆；错词和到期词用真题语境填空。
- 所有关键中文词义、句子译文和结构数据在构建时生成并静态保存，做题时不依赖临时翻译接口。
- DeepSeek 只负责需要智能判断的部分：构建阶段的语境词义/译文/句法数据，以及运行时的翻译评分与每日微调。

## 目录

```text
assets/                     四张用户指定图片
data/source/                2020—2026 抽取后的原始训练数据
data/generated/             构建完成后的本地双语题库
scripts/                    词典、AI增强、编译、验收脚本
worker/                     DeepSeek 运行时安全代理
.github/workflows/          GitHub Actions 一键构建题库
index.html                  网站入口
styles.css                  页面样式
app.js                      训练逻辑、记忆、复习、统计、音效
config.js                   只填写 Worker URL；绝不能写 API Key
```

- 四个训练池：600 句，ID 互不重复。
- 英译汉：200；汉译英：200；自由翻译：100；成分分析：100。
- 成分分析分层：30 精拆 + 30 粗拆 + 40 主干。
- 原始词形候选：5472 条；最终发布前会通过 ECDICT 词典、lemma 合并、专名/简单词过滤和 DeepSeek 语境义校准，只有完整可靠的数据才进入 3000 词正式表。
