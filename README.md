# 考研英语一真题训练器 V4 · Anatomy

在 V3 记忆/遗忘曲线版基础上新增“长难句三阶段训练”：

1. **阶段 1：逐词精拆（20 句）**：2023—2026 英语一 Part C 第 46—50 题，逐词归入主句、宾语/表语从句、定语从句、状语、非谓语、插入说明、逻辑连接等结构槽位；显示人工结构地图、主干、压缩句与参考汉译。
2. **阶段 2：层级强化（最多 120 句）**：从其余长句中按连接词/标点做较粗层级训练，重点是区分主句与从属修饰，不再逐词抠细节。
3. **阶段 3：主干压缩（全部长句）**：点击认为必须保留的主干词，并尝试把长句压成最短核心句。系统不给粗略自动分析做“死判分”，避免把启发式结果冒充唯一语法答案。

V4 继续沿用原网页的本地记忆、错题、遗忘曲线和导入/导出机制。上传覆盖 GitHub Pages 原仓库即可。
