# 考研英语一真题训练器 2023—2026 · V3 MEMORY

V3 在 V2 全量题库基础上加入了真正的浏览器内置记忆和每日间隔复习。

## V3 新增

- 学习记录永久保存在同一 GitHub Pages 网址、同一浏览器的 LocalStorage 中。
- 自动记住：哪些词见过、答对次数、答错次数、当前错题强度、记忆级别、下次复习日期。
- 遗忘曲线式复习间隔：1、2、4、7、15、30、60、120 天。
- 新模块「复习词汇 · 遗忘曲线」：只抽当天到期的词，放回真题原句做四选一语境填词。
- 「错题强化」与「到期复习」分开：错题可以立即反复强化，到期复习负责长期记忆。
- 语境选择优先从完整真题句库中寻找，而不是只使用截断片段。
- 复习选择项只显示英文，避免中文提示泄漏答案；答题后才显示中文核心义、真题原句、词典信息和下次复习日期。
- 单词释义优先级：人工/已有词典数据 → Free Dictionary API 英英释义 → 将英英释义转为中文训练参考义；词组无法查到单词型词典时保留已有词组释义/参考翻译。
- 英英词典释义、音标首次查询后缓存在浏览器，不重复请求。
- 新增「导出记忆 / 导入记忆」JSON 备份，可用于换浏览器或换电脑后手动迁移学习进度。
- 自动迁移 V2 的 LocalStorage 学习记录到 V3，网页升级不要求从零开始。

## GitHub Pages 更新

如果 V2 已经发布到 GitHub Pages，不需要新建仓库，也不需要重新设置 Pages。
只需把 V3 中的 `index.html`、`app.js`、`styles.css` 覆盖上传到原仓库根目录；`data.js` 与 `generated-data.js` 可以一起覆盖，以保证版本一致。Commit 后等待 GitHub Pages 自动部署即可。
