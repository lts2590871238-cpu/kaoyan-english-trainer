# 考研英语一真题训练器 V5 Stable

V5 重点先解决“词义/翻译可靠”和“页面不要等待”。练习页面不再临时调用在线翻译接口；词汇中文释义、英英定义和句子参考译文都优先从本地静态数据读取。

## V5 关键变化

- 词汇连线不再逐组联网查词，打开即出题。
- 删除 `释义暂不可用` 作为正常练习选项；本地没有可靠释义的词暂不抽取。
- 忽略 V3/V4 中可能已经缓存的错误在线翻译，学习进度仍保留。
- 词汇静态数据由 ECDICT 生成：中文释义 + 音标 + 英英定义。
- 真题句参考译文在构建阶段一次生成，练习时不联网等待。
- 清理自动抽出的垃圾词组、OCR 残片、考试说明词和明显专名缩写。
- 首页改为紧凑仪表盘，删掉宣传式说明文字。
- 词汇连线、拼句、汉译、复习、错题、长难句内部版式均压缩并统一。

## 自动补全本地词典

仓库包含：

- `.github/workflows/build-bilingual-data.yml`
- `scripts/build-generated.mjs`
- `package.json`
- `quality-data.js`

将这些文件一起上传到 GitHub 后，Actions 会自动用 ECDICT 建立本地词典，并为句库生成本地参考译文，然后把 `generated-data.js` 提交回 `main`。Pages 继续从 `main / (root)` 发布即可。

构建完成后，练习页面不依赖实时词典/翻译网络请求。
